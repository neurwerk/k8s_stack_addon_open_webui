# Operations

Clients supply exact browser callback, origin and logout approvals and select gateway model access. Generated nonsecret OIDC settings feed Base's scoped provisioning Job; credential delivery uses direct Secret references.

Stage settings and secret-delivery objects before workstation setup. Gate database, identity and application consumers on their required ExternalSecrets being Ready. Preparation preserves valid encryption/signing keys; refresh, provisioning, explicit restart and rotation are separate operations.

Use maintenance downtime for ownership transfer. Relinquish old Helm ownership before ESO adopts the final application Secret, and prevent old Flux inventories from pruning transferred objects. This is not approval to delete namespaces, databases or volumes.

A staged manifest or candidate wheel is not installable release evidence. Publish dependencies and tooling in order, verify immutable digests, and explicitly verify public package visibility and anonymous pulls before adoption. Follow the [shared release procedure](https://github.com/neurwerk/docs/blob/main/dev/operations/image-releases.md) and [OpenBao procedure](https://github.com/neurwerk/docs/blob/main/dev/operations/openbao.md).
